# Blockchain
Esse projeto é a criação de uma "rede blockchain" com funcionalidades simplificadas. Nela é possível criar carteira, fazer transações em blocos na blockchain, verificar a validade da cadeia e das transações, além de possuir o histórico de transações armazenado em memória. Esse projeto faz parte da 2° atividade individual do programa de bolsas da Compass UOL. 

## Pré-requisitos
Certifique-se de possuir o seguinte pacote:

- [Node.js](https://nodejs.org/en/download/package-manager)

## Instruções gerais
Abra o terminal e no diretório do projeto execute o seguinte comando:

```
 $ node index.js
```
